## Что не учтено во внутренних системах:
1) Подпись пациента в согласии на ПД
2) Журналы доступа к общему сетевому диску
3) Данные из электронной почты пациентов 
4) Нет аудита. При инциденте сложно будет узнать причины. 
5) Нет RBAC. Права нужна для разграничения доступов.
6) Отсутствие шифрования персональных данных.
7) Отсутствие классификации обрабатываемых данных.
8) Отсутствие мониторинга и реагирования на инциденты.

## Меры защиты

| Уязвимость                         | Меры защиты                                                      |
|------------------------------------|------------------------------------------------------------------|
| Общий сетевой диск                 | Включить аудит доступа                                           |
| Excel-журналы                      | Перенос журналов в 1С или Postgres с row-level-security          |
| Почта                              | MFA для всех почтовых учёток, TLS 1.2+ для транспорта            |
| Связка ККМ ↔ 1С                    | mTLS‑прокси между сервисом 1С и ККМ                              |
| Резервные копии                    | Шифрование бэкапов                                               |
| Хранение паролей                   | Внедрить корпоративный менеджер паролей                          |
| Нет аудита                         | Внедрение ELK стек                                               |
| Нет RBAC                           | Настройка RBAC в PostgreSQL, Kubernetes                          |
| Нет шифрования персональных данных | Использование  Vault                                             |
| Отсутствие классификации данных    | DLP-системы и политики                                           |
| Нет мониторинга и реагирования     | Внедрить систему SIEM для мониторинга и реагирования на инциденты |

## Модель тегирования

| Тег        |   | Правило присвоения         | Пример объекта     | Предпочтительные меры |
|------------|---|----------------------------|--------------------|-----------------------|
| PII_HIGH   |   | ПДн + мед. данные          | диагноз, анализ    | AES‑256               |
| PII_MEDIUM |   | ПДн без диагноза           | адрес, телефон     | HTTPS/TLS 1.3         |
| FIN_DATA   |   | Платёжные реквизиты        | чек ККМ            | Tokenization          |
