## Меры защиты
| Уязвимость                | Меры защиты                                                                 |
|---------------------------|------------------------------------------------------------------------------|
| Общий сетевой диск        | Включить аудит доступа                                                      |
| Excel-журналы             | Перенос журналов в 1С или Postgres с row-level-security                     |
| Почта                     | MFA для всех почтовых учёток, TLS 1.2+ для транспорта                       |
| Связка ККМ ↔ 1С           | mTLS‑прокси между сервисом 1С и ККМ                                         |
| Резервные копии           | Шифрование бэкапов                                                          |
| Хранение паролей          | Внедрить корпоративный менеджер паролей                                     |

## Модель тегирования

| Тег        |   | Правило присвоения         | Пример объекта     | Предпочтительные меры |
|------------|---|----------------------------|--------------------|-----------------------|
| PII_HIGH   |   | ПДн + мед. данные          | диагноз, анализ    | AES‑256               |
| PII_MEDIUM |   | ПДн без диагноза           | адрес, телефон     | HTTPS/TLS 1.3         |
| FIN_DATA   |   | Платёжные реквизиты        | чек ККМ            | Tokenization          |
